# Forever Companions 0.1.0 — beta

The companion game formerly bundled with Forever Waylaid is now a standalone addon.

- Open with `/fcp`, its minimap paw icon, or optional updated Waylaid shortcuts.
- Use `/fcp small` for a movable compact window, and `/fcp settings` for independent accessibility and appearance settings.
- Existing pets, memorials, tokens, supplies and tower progress import once when updated Waylaid is enabled on the same character. Original saves are retained.
- The same 100 creatures, adoption crates, care system, opt-in pet inspection and tower battles are included. No balance changes in this release.

See README.md before migrating an existing collection. Permanent pet death still applies. This is a beta release for testing, not 1.0.
