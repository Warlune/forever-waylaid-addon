# Forever Waylaid 0.14.0 and Forever Companions 0.1.0 — beta

- Split the pet game into **Forever Companions**, a separately installable addon with its own settings, saved variables, artwork, minimap launcher and compact window.
- Forever Waylaid now contains only delivery, auction, crafting and travel features. It works without the pet addon and retains optional pet shortcuts when both are enabled.
- Existing character pet collections are copied once when updated Waylaid and the companion addon are enabled together. The original save remains intact. New companion progress is never automatically replaced.
- The compact pet window can stay open beside the delivery compass and map.
- Added separate ZIP packaging and migration/independence regression checks. Pet balance is unchanged.

## Existing pet owners

Install both updated addon folders and restart the client. Enable both once on each character to import its pets, tokens, supplies and tower progress. Afterwards you can disable either addon. If you started a new stable first, companion Settings offers an explicit legacy import with a backup. Do not run Forever Companions alongside old bundled Waylaid 0.13.x; update Waylaid first.

Both addons remain beta, below 1.0. Guild testing of the split and multi-writ routes is still needed.
